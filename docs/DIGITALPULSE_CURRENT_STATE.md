## 2. Identified Product Gaps & Defect State

1. **Rust Agent Enrollment CLI**:
   - The Rust agent currently reads `DP_DEVICE_SECRET` directly from environment variables. It lacks an interactive CLI command (`dp-user-agent.exe enroll --token <token> --server <url>`) to consume one-time tokens (`dp_enroll_...`) generated by the admin dashboard and store the resulting secret securely.
2. **Manager & Live Employee Monitoring Table**:
   - The main dashboard overview has family/wellbeing remnants. It needs a crisp, professional **Live Employee Activity & Monitoring Table** displaying each employee's live status (`Active`, `Idle`, `Offline`, `Stale data`), current foreground app, current domain, active hours, and last update timestamp, with search, department filtering, and status filtering.
3. **Product Distraction Removal**:
   - The primary navigation contains remnants of consumer/family concepts (e.g., Pomodoro tasks, family members, digital wellbeing goals). These need to be cleaned up and refocused strictly on Enterprise Employee Activity Intelligence.
4. **Blocked Website Tracking Differentiation**:
   - Blocked website attempts are recorded in `PolicyViolation`, but need a dedicated view and clear distinction: blocked attempt count must **not** be conflated with or added to successful website usage duration.
5. **Real-time Event Streaming**:
   - Dashboard polling or WebSocket subscription for live status changes.
